# 陶晶驰 2.4 寸 TFT 触摸屏界面规范（320x240）

## 1. 页面结构
- `menu_assign`: 配置旋钮分配页面。
- `telemetry_power`: 发射功率页。
- `telemetry_swr`: 驻波页。
- `telemetry_smeter`: 信号强度页。

## 2. 统一布局
- 顶部状态栏（高度约 32px）：显示频率、模式、步进、CAT 状态、菜单超时。
- 主显示区：大数字显示关键值。
- 底部触摸热区：上一页 / 下一页 / 确认（运行页仅保留切页）。

## 3. 交互规则
- 触摸任意运行页 -> 切换下一个信息页（Power -> SWR -> S-Meter 循环）。
- 进入菜单后，配置旋钮 10 秒无操作 -> 自动退出到运行页。
- 菜单页支持“旋钮选择 + 触摸确认”双确认机制，避免误触。
